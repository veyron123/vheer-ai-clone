# Veo 3.1 AI Video Generation API

## Обзор

Интеграция модели Veo 3.1 через Kie API для генерации видео из текста и изображений. Модель поддерживает два режима генерации: качество (veo3) и быструю генерацию (veo3_fast) с расширенными возможностями контроля процесса.

## API Endpoints

### Создание задачи генерации видео

**Endpoint:** `POST https://api.kie.ai/api/v1/veo/generate`

**Аутентификация:** Bearer token в заголовке `Authorization`

## Параметры запроса

### Корневые параметры

| Параметр | Тип | Обязательный | Описание |
|----------|-----|-------------|----------|
| `prompt` | string | Да | Текстовое описание желаемого видео контента |
| `imageUrls` | array | Нет | Массив URL изображений (для image-to-video режима) |
| `model` | string | Нет | Тип модели: `"veo3"` (качество) или `"veo3_fast"` (быстрая) |
| `aspectRatio` | string | Нет | Соотношение сторон: `"16:9"`, `"9:16"`, `"Auto"` |
| `seeds` | integer | Нет | Seed для контроля случайности (10000-99999) |
| `callBackUrl` | string | Нет | URL для callback уведомлений |
| `enableFallback` | boolean | Нет | Включить резервную модель при ошибках |
| `enableTranslation` | boolean | Нет | Автоперевод промпта на английский |
| `watermark` | string | Нет | Текст водяного знака |

## Режимы генерации

### Text-to-Video
Генерация видео только из текстового промпта без изображений.

### Image-to-Video
Генерация видео на основе изображений:
- **1 изображение:** Видео развивается вокруг изображения динамически
- **2 изображения:** Первое - начальный кадр, второе - конечный кадр

## Модели

### veo3 (Качество)
- Высококачественная генерация видео
- Поддерживает как text-to-video, так и image-to-video
- Более длительное время обработки
- Лучшее качество результата

### veo3_fast (Быстрая генерация)
- Ускоренная генерация видео
- Поддерживает как text-to-video, так и image-to-video
- Быстрее время обработки
- Хорошее качество с оптимизацией скорости

## Пример запроса

```bash
curl -X POST "https://api.kie.ai/api/v1/veo/generate" \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -d '{
    "prompt": "A dog playing in a park",
    "imageUrls": ["http://example.com/image1.jpg"],
    "model": "veo3_fast",
    "aspectRatio": "16:9",
    "seeds": 12345,
    "callBackUrl": "https://your-domain.com/api/callback",
    "enableFallback": false,
    "enableTranslation": true,
    "watermark": "MyBrand"
  }'
```

## Пример ответа

```json
{
  "code": 200,
  "msg": "success",
  "data": {
    "taskId": "veo_task_abcdef123456"
  }
}
```

## Параметры детально

### prompt (обязательный)
- **Тип:** string
- **Описание:** Детальное описание желаемого видео контента
- **Рекомендации:**
  - Будьте конкретны в описании действий и сцен
  - Указывайте стиль, настроение и визуальные элементы
  - Для image-to-video описывайте как изображение должно оживать

### imageUrls (необязательный)
- **Тип:** array of strings (URL)
- **Описание:** Массив URL изображений для image-to-video режима
- **Поддержка:** 1 или 2 изображения
- **Требования:**
  - Доступные для API сервера URL
  - Поддерживаемые форматы: JPEG, PNG, WebP

### model (необязательный)
- **Тип:** string
- **Доступные значения:**
  - `"veo3"` - Качественная генерация
  - `"veo3_fast"` - Быстрая генерация (по умолчанию)
- **Описание:** Выбор модели для генерации

### aspectRatio (необязательный)
- **Тип:** string
- **Доступные значения:**
  - `"16:9"` - Ландшафтный формат (по умолчанию)
  - `"9:16"` - Портретный формат
  - `"Auto"` - Автоматический выбор
- **Важно:** Только 16:9 поддерживает 1080P разрешение

### seeds (необязательный)
- **Тип:** integer
- **Диапазон:** 10000-99999
- **Описание:** Контроль случайности генерации
- **Использование:**
  - Одинаковый seed = похожий контент
  - Разные seed = разный контент
  - При отсутствии назначается автоматически

### callBackUrl (необязательный)
- **Тип:** string (URL)
- **Описание:** URL для получения уведомлений о завершении задачи
- **Рекомендация:** Использовать для продакшена вместо polling

### enableFallback (необязательный)
- **Тип:** boolean
- **Описание:** Включить автоматическое переключение на резервную модель
- **Значения:**
  - `true` - Переключиться на резерв при ошибках
  - `false` - Не использовать резерв (по умолчанию)
- **Ограничения резервного режима:**
  - Только aspect ratio 16:9
  - Разрешение 1080P по умолчанию
  - Разный расход кредитов

### enableTranslation (необязательный)
- **Тип:** boolean
- **Описание:** Автоматический перевод промпта на английский
- **Значения:**
  - `true` - Перевод включен (по умолчанию)
  - `false` - Использовать оригинальный промпт

### watermark (необязательный)
- **Тип:** string
- **Описание:** Текст водяного знака на видео
- **Использование:** Добавляет брендинг к сгенерированному видео

## Коды ответов

| Код | Описание |
|-----|----------|
| 200 | Успех - запрос обработан успешно |
| 400 | 1080P обрабатывается, готовность через 1-2 минуты |
| 401 | Неавторизован - отсутствует или неверный токен |
| 402 | Недостаточно кредитов |
| 404 | Ресурс не найден |
| 422 | Ошибка валидации параметров |
| 429 | Превышен лимит запросов |
| 455 | Сервис недоступен (техническое обслуживание) |
| 500 | Внутренняя ошибка сервера |
| 501 | Ошибка генерации видео |
| 505 | Функция отключена |

## Callback уведомления

При указании `callBackUrl` система отправляет POST запросы на указанный URL при завершении задачи.

### Формат callback
```json
{
  "code": 200,
  "msg": "success",
  "data": {
    "taskId": "veo_task_abcdef123456",
    "state": "completed",
    "resultUrl": "https://example.com/generated-video.mp4"
  }
}
```

## Важные замечания

### Аутентификация
- Все запросы требуют Bearer токен в заголовке `Authorization`
- Получить API ключ можно на [странице управления ключами](https://kie.ai/api-key)

### Ограничения
- Максимальное количество изображений: 2
- Поддерживаемые форматы изображений: JPEG, PNG, WebP
- Изображения должны быть доступны для API сервера
- Разрешение видео зависит от aspect ratio и модели

### Рекомендации
- Используйте детальные промпты для лучших результатов
- Указывайте желаемые движения камеры
- Описывайте освещение и атмосферу
- Для image-to-video указывайте как изображение должно оживать

### Fallback режим
- Автоматически активируется при определенных ошибках
- Требует aspect ratio 16:9
- Использует 1080P разрешение
- Разный расход кредитов
- Видео недоступны через Get 1080P Video endpoint

## Получение результатов

### Через callback (рекомендуется)
Настройте endpoint для получения POST уведомлений о завершении задач.

### Через polling
Используйте taskId для периодической проверки статуса задачи.

### Прямая загрузка
После успешного завершения задачи видео доступны по прямым ссылкам в результатах.
